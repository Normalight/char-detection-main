中文字符标注工具 · Mac 使用说明

一、首次打开（未使用 Apple 开发者签名及公证）

1. 适用于 Apple Silicon（M 系列）Mac，请下载 arm64 安装包。需要 macOS 14 或更新版本。
2. 解压，将“中文字符标注工具.app”拖到“应用程序”，双击打开。无需安装 Python 或另行下载模型。
3. 如果提示“无法验证开发者”或“Apple 无法检查”，先关闭提示，再打开“系统设置 → 隐私与安全性”，找到此应用，点击“仍要打开”，按提示确认。之后可以正常双击。
4. 只对确认来源可信的本项目应用允许打开。如果提示文件已损坏，请重新下载完整压缩包；如果明确提示包含恶意软件，不要继续打开。

二、使用方法

1. 选择包含图片或 PDF 的输入文件夹，以及专用输出文件夹。粒度选择 char，点击“开始”。
2. 等待预标注完成，在画布检查单字框，按需创建、旋转或删除。
3. 保存当前页后继续翻页；退出时按提示保存，并等待后台完成。
4. 输出目录包含单字 PNG、标注 JSON 和每页 Excel，可交给“字形归并工具”继续整理。
5. 常用快捷键：先点击画布；C 创建、R 旋转、O 导航、+/- 缩放、N/B 切框、A/D 翻页、X 或 Delete 删框、S 保存。
